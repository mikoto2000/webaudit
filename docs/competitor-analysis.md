# Competitor analysis

Local sources inspected read-only: AuraDFIR app/analysis/{rules,engine,statistics,parameters}.py, app/ingest/parser.py, app/correlation/timeline.py and tests/test_rules.py; CrowdSec pkg/leakybucket/bucket.go; Hub HTTP scenarios, base-http-scenarios/http-cve collections and parsers/s01-parse/crowdsecurity/{apache2-logs,nginx-logs,http-logs}.yaml where present. Exact snapshots and root licenses in THIRD_PARTY_NOTICES.md. Per-file header inspection found no overrides for selected rules. No opaque remote data file is copied.

AuraDFIR centralizes 25 URL regex signatures (see machine inventory for actual count), scanner substring lists and method lists. Its ES engine aggregates 401/403 in fixed 5-minute windows, 404 counts, response bytes, rare UAs and hourly z-scores. Timeline uses IP+UA, 30-minute gaps, recon/exploitation/post-exploitation labels. Its parser uses regex, optional vhost/UA and original evidence. WebAudit avoids inferring hosts from Referer and preserves missing sizes as null. Broad curl/python client labels, redirect URL presence and normal admin routes can be false positives; adapted signatures are deliberately narrower.

CrowdSec buckets use capacity, leakspeed, distinct keys, groupby and blackhole suppression; counter/trigger scenarios have different overflow semantics. WebAudit implements bounded event-time rolling counts and a leaky accumulator independently; it does not embed the CrowdSec runtime or expression evaluator. Access-only 401 sequences are proxies for failed authentication, never verified credentials. Meta.sub_type=auth_fail often originates from error/application logs, unavailable in standard access logs.

Hub base-http-scenarios depends on http-logs parser and http-cve collection; individual scenarios may require File() datasets, parsed args, target FQDN, static-resource markers, country/ASN enrichment, or application logs. A WAF/body rule cannot be evaluated from a URL alone. Inventory explicitly records exclusions; condition-level adaptations do not reproduce upstream thresholds/data coverage exactly. External lists are not downloaded at runtime. Log4Shell/Spring4Shell URL/UA evidence records attempts, never code execution.
