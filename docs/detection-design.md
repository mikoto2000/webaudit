# Design decisions

Go 1.27.4 selected from official https://go.dev/dl/?mode=json on 2026-11-20 (latest stable returned). Download SHA-256 checked against metadata. Go toolchain kept outside repository. Only standard library: flag, bufio, gzip, regexp (RE2), embed, html/template, encoding/json/csv. No external dependency maintenance burden, service, network import or config required at runtime.

Pipeline: discover regular input files -> bounded line streaming -> strict auto parser -> bounded URL variants -> L1 JSON signatures -> L2 event-time windows/leaky bucket -> L3 sample-aware statistics -> L4 incident correlation -> L5 cautious outcomes -> stdout/HTML/JSON/CSV. File errors isolated. Source text and file/line preserved in bounded evidence samples. Missing optional fields are null. Unrecognized layouts fail explicitly with fields and --log-regex named-group alternative. XFF never changes source IP. vhost is retained to prevent merging different targets.

Resource bounds: maximum line, decompressed bytes per file, tracked keys/windows, distinct values, dedup fingerprints, incidents and evidence samples. Reaching a bound is disclosed; completeness is never implied. Arbitrary shuffled logs cannot be sorted in unbounded RAM; fixed event-time buckets accept cross-file reorder within retained key budget; expired/dropped state is disclosed. Exact duplicates within the fingerprint horizon are excluded from detection, counted separately; natural identical requests may be indistinguishable.

L1 attack score weights critical/high/medium/low = 40/30/15/5, sum of unique rule IDs capped at 100. Statistical and behavior findings indicate anomalies, not malicious intent. L4 links IP + target host + UA + category family within five-minute event-time partitions; global statistics stay separate. Cross-category behavior supplies an explicit related-activity signal, never merges all IP history. Categories and phases represent observed technique, not proven progression.

L5 unknown is default. Repeated nonempty 2xx sensitive-resource responses following blocked probes may suggest exposure, with confidence <=0.55, and require content/application corroboration. Repeated blocked responses suggest failure <=0.55, never confirmed. 200/302/500 alone cannot prove success. Confirmed states exist in schema but are not emitted by access-only evidence. Score and outcome confidence remain independent.

Statistics: >=20 peer groups or baseline samples; robust median/MAD with nonzero floors and minimum effect sizes. IP request and error-rate peers; response-size and per-URL historical baselines; hourly counts including zeros only within bounded observed span. No training data means abstention. Full thresholds, bounds, approximation and verification recorded in implementation/tests and detection-coverage.md.

TDD: each implementation phase starts with committed RED behavioral tests; GREEN commits plus no-ff merges retain evidence without merging failing main. Tests cover boundaries, benign counterexamples, malicious inputs and offline deterministic fixtures. No network-dependent tests. Local PR substitutes record checks when GitHub auth unavailable.
