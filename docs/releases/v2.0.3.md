# WebAudit v2.0.3

分析時のルール照合と統計計算を高速化したパッチリリースです。

## 変更点

- Aura署名・独自ルール・上流データの正規表現を必須文字列で事前選別し、不必要な照合を減らしました。最終判定は従来のRE2のままです。Unicode・不正UTF-8入力は直接RE2で評価します。
- フィールド変換をルール間で共有し、固定リストを初期化時に大文字化して保持します。
- オンラインの中央値・MAD計算で128要素の作業領域を再利用し、観測順序と統計閾値を維持します。
- 性能比較ツール・生データ・検出結果の一致検証を追加しました。

Windows開発機で前後交互に各3回測定した通常10万行の中央値は23.055秒から4.079秒（5.65倍）、累計割当量は78.6%減少しました。長いUA・攻撃20%混在の1万行でも比較しています。既存コーパス等の180レポートと性能測定の全反復でレポート一致を確認しました。

詳細な条件・結果・制限は[性能測定](https://github.com/mikoto2000/webaudit/blob/v2.0.3/docs/performance.md)を参照してください。単一環境の合成ログであり、GeoIP・gzip・bundle生成全体の性能は未計測です。長いUA条件は既存のサンプル切り詰めにより前後とも部分解析です。

## 互換性と配布

従来CLI・レポート・watchの動作と検出の最終判定を維持します。ルール版は`2026.11.20.2`です。公開サンプルは生成時点のスナップショットを保持します。

Windows / Linux / macOSのamd64・arm64向けバイナリ6種類と、`SHA256SUMS.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.md`を配布します。
