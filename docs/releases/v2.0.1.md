WebAudit v2.0.1は、統計解析の終了時処理と資源上限の案内を改善するパッチリリースです。

## 変更点

- IPごとのリクエスト数・バイト数・HTTPエラー率と、時間帯ごとの外れ値判定で、同じ母集団の中央値とMADを一度だけ計算します。終了時の計算量を O(n² log n) から O(n log n) に抑えます。
- gzip入力の処理時間と、`--max-file-bytes` の設定例、上限超過時の部分解析・再実行方法をREADMEに追記しました。
- HookのJSON入力を信頼しないこと、シェルへ展開しないこと、引数配列と標準入力で受け渡す例を設計書に追記しました。64 KiBを超える通知は破棄する仕様も明記しました。

## 互換性

検出閾値、20サンプル以上という判定条件、欠損値の扱い、ゼロ件の時間帯を含む基準値、出力スキーマは維持します。gzip展開後の既定上限も8 GiBのままです。オンライン応答サイズ判定は、観測ごとに更新される基準値を引き続き使用します。

Windows / Linux / macOSのamd64・arm64向けバイナリ6種類と、`SHA256SUMS.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.md`を添付します。
