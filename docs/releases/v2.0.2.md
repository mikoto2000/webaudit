# WebAudit v2.0.2

調査報告書の出力と証跡の追跡、解析中の進捗表示を改善したパッチリリースです。

## 変更点

- `--report-dir`で11章構成の日英HTML、共通JSON、CSV別紙、manifestを新規ディレクトリへ生成します。任意の調査名・対象システム・背景・目的・担当者を指定できます。
- 事案と独立したHub/Aura検出の一覧・詳細・一覧へ戻るリンク、生ログ代表例、事実・推定・未確認事項・条件付き影響・推奨対応を表示します。従来HTMLの一覧と生ログ参照も改善しました。
- 不審・関連リクエスト全件を元file/lineとIDへ関連付け、複数ルール・エンジンの一致を重複観測数へ加算しません。集計条件への関連と直接検出を区別します。
- 全アクセス・不審アクセスの統計、時系列、取得可能な国/ASN、41調査観点と全既存ルールのカバレッジを出力します。未対応・評価不能・未実施と無検出を区別し、国DBだけでASN類似性を評価済みとしません。
- gzipを含む原本bytesの前後SHA-256、入力別診断、実効設定・ルール・DB来歴、成果物SHA-256を記録します。失敗時はINCOMPLETEを残し、証跡と出力容量の上限を設けます。
- 一般的な秘密値のマスク、制御文字の可視化、HTML escapeとCSV数式対策を適用します。数値の0/欠損/不正を区別し、不審件数の下限品質を別紙にも明示します。
- `--verbose`で処理中ファイルと読み取り進捗を標準エラーへ表示します。標準出力のレポート形式は維持します。
- 日英サンプル、要求対応表、統合・セキュリティ・オフライン検証と性能・メモリ・ディスクの実測資料を追加しました。

```sh
webaudit access.log access.log.1.gz --report-dir report-ja --lang ja --system-name "対象システム"
webaudit access.log --report-dir report-en --lang en --verbose
```

## 互換性と制限

従来のCLI・単一HTML/JSON/CSV・watch・成否判定を維持します。報告書は明示モードで、既存の出力先を上書きせず、`-o`/`--format`との併用はできません。ルール版は`2026.11.20.2`のままです。公開サンプルは生成時点のバージョン・環境を記録したスナップショットです。

アクセスログだけで侵入成功・失敗を確定しません。本文専用攻撃やIP reputation等は未対応、未校正の検出確度はunknownです。秘密マスクは全個人情報の匿名化を保証しません。容量・保持上限では部分解析と下限件数を明示します。

[出力仕様](https://github.com/mikoto2000/webaudit/blob/v2.0.2/docs/reporting/output.md)、[検証・要求対応](https://github.com/mikoto2000/webaudit/blob/v2.0.2/docs/reporting/traceability.md)、[資源測定](https://github.com/mikoto2000/webaudit/blob/v2.0.2/docs/reporting/performance.md)を参照してください。

Windows / Linux / macOSのamd64・arm64向けバイナリ6種類と、`SHA256SUMS.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.md`を配布します。
