WebAudit v1.1.0では、GeoIP / ASN情報の付加と、DB-IP Liteの取得・更新管理に対応しました。

## GeoIPをワンコマンドで導入

```sh
webaudit geoip download
webaudit access.log -o report.html
```

取得済みDBは通常解析で自動利用します。更新は`webaudit geoip update`、状態・整合性の確認は`webaudit geoip status`です。保存先は絶対`XDG_DATA_HOME/webaudit/geoip`を優先し、未設定時はLinux/macOSの`~/.local/share/webaudit/geoip`、Windowsの`%LOCALAPPDATA%\webaudit\geoip`を使います。手持ちのDBを指定する`--geoip-country` / `--geoip-asn`も利用できます。

## 安全な更新とオフライン解析

- 通信するのは`geoip download` / `geoip update`のみ。通常解析・検索・status・レポート生成はオフラインです。
- Country/ASNを検証後、世代単位で一括切替します。更新失敗時は既存DBを保持し、`geoip rollback`で保持した前世代を復元できます。
- DB未導入でも従来どおり解析できます。管理DB破損は警告してGeoIPなしで継続し、明示指定したDBのエラーは解析前に通知します。
- DB本体は実行ファイル・リリースへ同梱しません。

## 調査情報とレポート

IPv4/IPv6、国・ASN・組織名、検索状態、DBの版・取得/ビルド日時をCLI・HTML・JSON・CSVに追加しました。国別/ASN別の事案・IP数と、対象パス・技法・時間帯が類似する同一ASN内の複数IPを調査用に表示します。国・ASNだけで危険度や攻撃成功の確信度を上げません。GeoIP無効時の出力互換性を維持しています。

キャッシュ・集計の保持数には上限があり、超過時は部分解析・件数の下限を明示します。DB-IP Liteの所在地・ASN情報は調査補助であり、個人の所在や攻撃主体を確定する情報ではありません。

## 配布と検証

Windows / Linux / macOSのamd64・arm64向けバイナリを添付しています。ファイルの確認には`SHA256SUMS.txt`を使用してください。ライセンス全文は添付の`LICENSE`と`THIRD_PARTY_NOTICES.md`にあります。

235件のテスト結果が成功し、更新失敗・復旧・同時実行・ロールバックと、Linuxでのネットワーク禁止下の解析を検証しました。100万行の測定結果と制限は[GeoIP検証記録](https://github.com/mikoto2000/webaudit/blob/v1.1.0/docs/geoip-testing.md)を参照してください。macOS/ARM64はクロスビルドを確認しており、実機での動作検証は行っていません。
