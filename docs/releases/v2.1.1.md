# WebAudit v2.1.1

HTML レポートの判定指標と解析範囲を読み取りやすくしたパッチリリースです。

- 攻撃スコアと成否の確信度の凡例を追加し、確信度が成功確率ではないことを明記しました。
- 冒頭に解析状態、WebAudit・Hub・Aura別の件数、警告と入力ファイルへのリンクを表示します。異なる集計単位の件数は合算できません。
- タイムゾーン不明の事案で記録上の時刻範囲を表示し、UTC換算できないことを明記します。範囲がない場合は保持した証拠へ案内します。
- README の一括解析手順と継続監視手順を整理し、端末の調査案内の言語仕様を明記しました。同梱HTMLサンプルも更新しました。

検出ルール・判定条件・既存CLIの互換性は維持します。
