WebAudit v1.2.0では、HTMLレポートの日本語・英語切り替えと、攻撃の種類に応じた追加調査の案内に対応しました。

## 主な変更

- HTMLレポートの既定言語を日本語にしました。`--lang ja` / `--lang en`で表示言語を選べます。判定理由、警告、GeoIPの説明、攻撃別の確認案内も切り替わります。
- SQLインジェクション、コマンド実行、機密ファイル、XSS、認証試行、大量アクセスなど、検出の種類に応じて「不明な理由」「確認する場所」「何が見つかれば判断できるか」を案内します。HTMLの事案詳細と端末の上位5事案に表示し、JSONの`outcome.investigation`とCSVの`details_json`にも含めます。
- 元ログ、URL、IP、User-Agent、DBの国名・組織名などの証拠データは原文を保持します。`--lang`はHTMLに適用し、端末の要約・ヘルプ・JSON・CSVの言語は変更しません。

## 修正

- Aura由来の集計が保持上限に達した後も、保持済みのキーの観測を集計するよう修正しました。
- 自動探索したGeoIP DBが利用できない場合の警告と、検索時の警告保持を改善しました。
- レポート出力の書き込み・クローズに失敗した場合、不完全な出力ファイルを削除するようにしました。
- HTMLで期間・ホスト・User-Agent・ステータス・応答サイズの欠損値を明示し、端末出力ではUnicodeの双方向制御文字を無害化します。

## 利用時の注意

アクセスログだけで侵害の成功を確定できるとは限りません。追加調査の案内は確認の目安であり、新たな証拠の検出や成否の自動更新を意味しません。JSONは引き続き`webaudit/2`スキーマを使用します。

## 配布ファイル

Windows / Linux / macOSのamd64・arm64向けバイナリ6種類と、`SHA256SUMS.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.md`を添付します。取得したファイルのSHA-256を一覧と照合してください。macOS / ARM64はクロスビルド対象で、実機での動作検証は行っていません。
