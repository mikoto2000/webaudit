{{t "3. Analysis methods"}}

  1. {{t "Regular files are discovered in deterministic path order and streamed with bounded line and decompressed-file sizes; gzip is identified by content."}}
  2. {{t "Strict supported parsers preserve source file and line. Custom formats require explicit named capture groups; the regex body is not stored in the manifest."}}
  3. {{t "URL normalization emits bounded decoding and case/slash variants for detection; it does not establish how the application interprets the request."}}
  4. {{t "Known offsets are retained and timeline bins use UTC. Timezone-free error records need an explicit error timezone for cross-log time comparison."}}
  5. {{t "L1 signatures, overlapping five-minute behavior windows, leaky buckets and sample-aware median/MAD anomalies reuse the existing engines."}}
  6. {{t "Incidents group recorded IP, host, User-Agent, technique family and five-minute partition. This is a correlation hypothesis, not verified identity or attack progression."}}
  7. {{t "Hub and Aura source detections remain independent. GeoIP and ASN similarity provide investigation context without changing attack scores or outcomes."}}
  8. {{t "Full request snapshots are spooled under a disk limit, then associated with completed detections. Aggregate members may be normal and are exported as related evidence."}}
  9. {{t "Confirmed success or failure is not inferred from an HTTP status alone. Existing outcome guidance identifies corroborating evidence to collect."}}
